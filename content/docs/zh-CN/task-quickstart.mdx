<h2 id="prepare">准备资料</h2>

确认当前 Profile 有 Task Agent 使用权限。准备一份不含敏感信息的会议记录，或直接把记录贴到输入框。这个例子只整理已有内容，无需连接外部应用。

不确定选择哪个模型时，可以使用 Auto。候选模型、默认模型和计费方式见[选择 Auto 模型](task-capabilities#auto-model)。

<Steps titleSize="h2">

<Step title="提交任务" id="prompt" stepNumber={1}>

打开“新对话”，输入以下要求，把最后一段替换为实际记录：

```text
请把下面的会议记录整理成中文纪要。
区分已经决定的事项和仍需讨论的问题。
行动项请列出事项、负责人、截止日期；原文没写的地方标为“待确认”。
最终生成一份 Markdown 文件，并在回复里概括需要我检查的内容。

会议记录：
客服希望增加订单查询功能。第一版只查状态，不修改订单。
小林负责确认接口字段，周五前给出结果。上线时间还没有确定。
```

也可以使用上传按钮附上文件，等待上传成功后再发送。

</Step>

<Step title="查看执行进展" id="plan" stepNumber={2}>

发送后 Agent 开始执行。查看回复和执行记录；若范围、输出格式或资料来源不对，可继续补充说明。需要中止当前工作时使用停止操作。

例如，Agent 打算补充行业背景，而你只需要会议纪要，可以说明“只整理这份记录，不需要查找外部资料”。

</Step>

<Step title="检查与下载" id="result" stepNumber={3}>

执行完成后，检查负责人、日期和事项是否来自原文。在对话菜单选择“查看聊天中文件”，下载生成的 Markdown 文件。

需要修改时直接在当前对话补充：“把行动项改成表格，并保留待确认项。”遇到问题可参考 [常见问题](task-troubleshooting)。

</Step>

</Steps>
