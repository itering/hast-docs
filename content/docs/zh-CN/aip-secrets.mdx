<h2 id="create">创建机密</h2>

<Note>

打开机密页面，填写名称和值后保存。例如，把订单系统的令牌保存为 `ORDER_API_TOKEN`。保存后列表只显示名称等信息，机密值不会再次显示。

</Note>

<h2 id="bind">在 Agent 中绑定</h2>

1. 进入 Agent 编辑页的机密绑定设置。
2. 选择当前 Profile 下已保存的机密。
3. 在业务 HTTP 工具的请求头中引用该名称。
4. 保存 Agent，用调试验证业务接口能正常认证。

```text
Authorization: Bearer ${ORDER_API_TOKEN}
```

这里的占位符名称需要与已绑定机密一致。只创建机密而没有绑定，不能让工具获得该凭证。

如需把凭证作为文件提供给运行环境，可使用文件绑定，并按界面设置路径和解码方式。仅在工具确实需要文件凭证时配置。

<h2 id="rotate">更新和删除</h2>

更新机密只替换值，名称不变。业务系统轮换令牌后，在机密页面更新对应条目，再测试一次调用。

仍被 Agent 或会话引用的机密可能无法删除。先移除相关绑定；保存成功后再删除机密。Agent 调用地址中的凭证与这里保存的机密用途不同，见 [HTTP 接入](aip-api)。
