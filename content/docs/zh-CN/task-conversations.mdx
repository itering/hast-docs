<h2 id="request">写清任务要求</h2>

告诉 Agent 要完成的工作，以及你会怎样检查结果。涉及文件时指出具体文件；涉及时间范围时写出日期；需要联网或外部应用时说明资料来源。

```text
分析我上传的销售表格，按月份汇总收入，并列出缺少金额的记录。
不要把空值按 0 计算。输出一份 CSV 和一段中文说明。
```

<h2 id="execute">查看执行过程</h2>

发送需求后 Agent 开始执行。你可以查看消息、工作计划、工具活动和任务状态，并继续补充要求。需要改变范围时，先确认已完成的操作；必要时停止当前工作再调整。

“正在准备”或“已排队”表示任务仍在等待运行条件。发送按钮暂不可用时，查看当前运行状态，避免反复提交相同需求。

<h2 id="stop">停止与继续</h2>

需要中止当前工作时使用停止按钮。仅关闭网页不会等同于发出停止指令。状态更新后，在当前对话说明要调整的要求，再继续任务。

<Note>

如果已执行的操作写入了外部系统，停止后应到对应系统确认结果。停止不会自动撤回已经完成的操作。

</Note>

<h2 id="history">管理历史对话</h2>

在“最近”列表重新打开对话。通过操作菜单可以重命名，方便按项目或日期查找；标题不能为空。

删除对话需要确认，且无法通过界面撤销。先下载需要保留的产物，再删除不再需要的对话。
