<h2 id="configure">填写文章要求</h2>

发起 `Run Article Agent`，根据文章目标填写配置。

| 配置 | 说明 |
| --- | --- |
| 风格 | 操作指南、技术详解、对比、问题与解决方法、数据与观点 |
| 语言 | 自动、英文或中文 |
| 目标读者 | 说明谁会阅读文章，以及他们已经了解什么 |
| 漏斗阶段 | 自动，或选择顶部、中部、底部 |
| 主题 | 这篇文章要回答的具体问题 |
| 目标查询 | 希望覆盖的搜索问题或关键词 |

例如，面向已经了解产品的开发者，可以选择中文、操作指南，并把主题写成“如何把订单查询助手接入客服系统”。

<h2 id="generate">等待草稿生成</h2>

提交后查看任务状态。一次任务生成一篇长文 Markdown 草稿，完成后在 Agents Feed 查看。

也可以让 Growth Agent 发起文章任务。需要落到 Feed 的内容，应明确要求运行 Article Agent，避免只在聊天里得到一段回答。

<h2 id="review">检查并使用</h2>

打开文章预览，核对标题、产品事实、数据出处和链接。使用复制 Markdown 的操作把正文带到自己的内容系统，再按发布平台要求编辑。

<Note>

生成草稿不代表已发布到网站。涉及尚未开放的功能、客户案例或效果数字时，应先核实再使用。

</Note>
