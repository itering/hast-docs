<h2 id="start">开始调试</h2>

先保存 Agent，再从详情页进入调试；也可以打开调试页，选择当前 Profile 的 Agent。

1. 创建调试会话。
2. 输入一条能验证主要职责的消息。
3. 查看回复和事件数据。
4. 发送追问，检查是否保留对话上下文。

调试会真正执行配置中的工具。如果工具会写入业务数据，使用你有权限操作的测试对象。

内容过长，已缩略显示；执行不受影响。

<h2 id="check">检查结果</h2>

| 检查项 | 示例 |
| --- | --- |
| 输入完整 | 缺少订单号时是否询问，而不是编造一个号码 |
| 资料使用 | 是否使用了正确知识库，是否承认资料缺失 |
| 工具调用 | 是否传入正确参数，认证失败是否有清晰错误 |
| 输出格式 | 是否符合系统提示词规定的格式 |
| 连续对话 | 追问是否围绕当前会话继续 |

<h2 id="stop">停止与重连</h2>

需要中止时点击停止。断开事件连接或关闭页面不会等同于停止运行。

连接中断后可按已读取的事件位置重新连接。调试会话状态保存在当前页面，离开前记录排查所需的会话标识和错误信息。

<h2 id="errors">常见情况</h2>

配置没有变化时，先确认已保存，并检查当前选择的 Agent。调用被拒绝时检查启用状态。工具认证失败时检查机密和绑定。找不到资料时确认知识库已完成索引，并已在 Agent 中选中。
