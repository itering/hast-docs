<h2 id="edit">编辑配置</h2>

在 Agent 列表打开详情，再进入编辑。表单和 JSON 模式使用同一份配置，切换模式后继续编辑，保存才会生效。

| 配置 | 填写建议 |
| --- | --- |
| 名称和描述 | 写明负责的业务，便于列表检索和调试时选择 |
| 系统提示词 | 说明输入是什么、如何处理、何时需要补充信息、如何输出 |
| 模型与推理强度 | 使用目录中的可用选项；不同模型支持的强度可能不同 |
| 调用状态 | 启用或停用外部调用 |
| 沙箱权限 | 根据任务是否需要写文件或执行操作选择 |
| Skills | 选择 Agent 需要的工作方法 |
| 知识库 | 选择已完成索引的资料 |
| 策略 | 开启任务需要的能力，例如检索或长期记忆 |

资源目录加载失败时先重试。刷新目录会保留当前草稿。添加知识库时，表单会启用知识库检索能力；其他能力仍需按配置检查。

缺少 CRM 或机密时，使用对应的“在新标签页配置”入口。保留原 Agent 编辑页，配置完成后回到原页点击“刷新 CRM 列表”或“刷新机密列表”，再选择新资源。刷新只读取资源目录，不替换名称、用途或高级设置草稿。关闭或整页刷新原标签页仍可能丢失未保存内容。

不确定选择哪个模型时，可以使用 Auto。候选模型、默认模型和计费方式见[选择 Auto 模型](task-capabilities#auto-model)。

<h2 id="assistant">使用配置助手</h2>

如果你的工作区提供此功能，可以打开配置助手，通过对话请求修改 Agent 和相关资源。权限模式按当前对话设置：

- **等我审批**：重要变更需要你审批。请在审批前检查待处理变更，并在执行后核对回执。
- **全部权限**：当前对话可以直接修改、删除或运行你有权限管理的资源。仅在适当时选择；助手无法恢复已删除的资源。

机密值请通过安全表单输入，不要发在聊天中。助手修改的是已保存配置，不会使用编辑页中未保存的草稿。完成后重新加载编辑页并核对草稿，再用新的调试会话验证结果。执行受支持的渠道设置时，对话中可能会显示配对二维码；请在对应应用中扫码并批准登录。助手保存的栅格图像也可能以内嵌预览和下载链接的形式显示。

<h2 id="save">保存与协作</h2>

保存会更新当前配置。Agent 没有配置版本历史或回滚界面；多人同时编辑时，以最后一次成功保存为准。调整重要提示词或工具前，可先导出一份配置文件。

离开有未保存内容的编辑页时，按页面提示选择保留编辑或放弃。完成保存后，使用新调试会话检查结果。

<h2 id="disable">停用和删除</h2>

暂时不希望接受调用时，停用 Agent。删除前先确认业务服务不再使用它的调用地址，并处理需要保留的配置和记忆。

如果 Agent 由你们的服务启动流程同步配置，控制台里的修改可能被下次同步覆盖。应先与维护该服务的人确定配置从哪里修改。

<h2 id="access">管理 Agent 权限</h2>

在所选工作区的管理导航中打开 **Agent 权限**，查看各 Agent 的成员与接入来源授权。打开某个 Agent 后，可搜索、筛选并分页查看成员、来源和历史授权记录。成员权限遵循工作区角色：Viewer 可以读取共享内容；Editor 和 Admin 可以编辑并运行 Agent。请在工作区成员页面管理这些角色。已保存的 Agent 单独只读限制和撤销记录仍然有效，可在成员视图中查看。渠道权限在“来源”视图中管理：选择 **启用渠道** 可以绑定一个已连接的渠道并允许该 Agent 在其上运行，也可以为已绑定的渠道恢复运行授权。此操作需要组织 Owner/Admin 或个人工作区所有者。一个渠道连接只有一个回复负责人，改派给其他 Agent 会撤销原 Agent 的渠道与会话授权。在渠道或 API 接入来源记录上，还可以启用计划任务管理或撤销授权。私人会话和个人连接仍遵循各自的访问规则。

按会话记录的授权和已撤销的授权会显示在历史记录中。仅保留历史授权的 Agent 会单独列在历史视图中，已有记录仍可查看。Agent 配置、计划任务和渠道仍在工作区工作台中管理。

<h2 id="directory-tasks">在 Agent 目录查看渠道和任务</h2>

在 AIP 工作区工作台中展开 Agent 行，可查看关联渠道和已保存任务。选择渠道可打开其设置。使用任务操作为该 Agent 创建任务，或打开已有任务。已保存的手动任务不是计划任务；目录中会标为**已保存**。自动运行请使用计划任务页面。任务达到 100 个时，目录列表可能不完整；请留意页面提示，不要据此认定未显示的任务不存在。
