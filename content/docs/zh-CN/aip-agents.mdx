<h2 id="edit">编辑配置</h2>

在 Agent 列表打开详情，再进入编辑。表单和 JSON 模式使用同一份配置，切换模式后继续编辑，保存才会生效。

| 配置 | 填写建议 |
| --- | --- |
| 名称和描述 | 写明负责的业务，便于列表检索和调试时选择 |
| 系统提示词 | 说明输入是什么、如何处理、何时需要补充信息、如何输出 |
| 模型与推理强度 | 使用目录中的可用选项；不同模型支持的强度可能不同 |
| 调用状态 | 启用或停用外部调用 |
| 沙箱权限 | 根据任务是否需要写文件或执行操作选择 |
| Skills | 选择 Agent 需要的工作方法 |
| 知识库 | 选择已完成索引的资料 |
| 策略 | 开启任务需要的能力，例如检索或长期记忆 |

资源目录加载失败时先重试。刷新目录会保留当前草稿。添加知识库时，表单会启用知识库检索能力；其他能力仍需按配置检查。

缺少 CRM 或机密时，使用对应的“在新标签页配置”入口。保留原 Agent 编辑页，配置完成后回到原页点击“刷新 CRM 列表”或“刷新机密列表”，再选择新资源。刷新只读取资源目录，不替换名称、用途或高级设置草稿。关闭或整页刷新原标签页仍可能丢失未保存内容。

不确定选择哪个模型时，可以使用 Auto。候选模型、默认模型和计费方式见[选择 Auto 模型](task-capabilities#auto-model)。

<h2 id="assistant">使用配置助手</h2>

如果你的工作区提供此功能，可以打开配置助手，通过对话请求修改 Agent 和相关资源。权限模式按当前对话设置：

- **等我审批**：重要变更需要你审批。请在审批前检查待处理变更，并在执行后核对回执。
- **全部权限**：当前对话可以直接修改、删除或运行你有权限管理的资源。仅在适当时选择；助手无法恢复已删除的资源。

机密值请通过安全表单输入，不要发在聊天中。助手修改的是已保存配置，不会使用编辑页中未保存的草稿。完成后重新加载编辑页并核对草稿，再用新的调试会话验证结果。

<h2 id="save">保存与协作</h2>

保存会更新当前配置。Agent 没有配置版本历史或回滚界面；多人同时编辑时，以最后一次成功保存为准。调整重要提示词或工具前，可先导出一份配置文件。

离开有未保存内容的编辑页时，按页面提示选择保留编辑或放弃。完成保存后，使用新调试会话检查结果。

<h2 id="disable">停用和删除</h2>

暂时不希望接受调用时，停用 Agent。删除前先确认业务服务不再使用它的调用地址，并处理需要保留的配置和记忆。

如果 Agent 由你们的服务启动流程同步配置，控制台里的修改可能被下次同步覆盖。应先与维护该服务的人确定配置从哪里修改。
