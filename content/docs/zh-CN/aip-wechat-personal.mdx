<h2 id="prepare">开始前</h2>

本指南适用于已提供「微信 → 个人微信」入口的部署。功能可用性取决于所在环境；本文不表示所有生产环境均已开放。

个人微信只将选定会话同步到知识库，不发送消息或已读回执。它与可用于客户服务回复的[微信客服](aip-wechat-kf)是不同的接入方式。新登录的账号不一定能获取手机上的完整历史记录。

<h2 id="deploy">部署与登录</h2>

在自己的服务器上安装 Docker，并按 [agent-wechat 官方安装指南](https://thisnick.github.io/agent-wechat/setup/install/)中的 Docker 部分启动服务。使用独立的持久化数据卷保存账号数据和登录状态，固定经过验证的镜像版本。

按[官方账号连接指南](https://thisnick.github.io/agent-wechat/setup/connect/)创建账号并扫码，在手机微信上确认。需要多账号时为账号设置易识别的别名。不要让两个进程同时写入同一份账号数据。

Hast 后端必须能够访问服务地址。服务器上的 `localhost` 仅代表那台服务器；远程 Hast 不能通过你的 `localhost` 连接。可以通过自己的反向代理或受保护的隧道提供 HTTP 或 HTTPS 地址。代理需要转发 Authorization 等鉴权头，并关闭事件流缓冲，允许长连接。

创建仅用于 Hast 的访问 Token，限制到所需账号，授予 `read`；启用附件下载时再增加 `media`。不要授予 `send`、`read-state` 或管理权限。账号 ID 仅在服务管理员配置 Token 时使用，Hast 页面会自动读取可访问的账号。

<h2 id="connect">连接 Hast</h2>

1. 打开「渠道 → 添加渠道 → 微信 → 个人微信」，选择「连接已有服务」。
2. 填写服务 URL。HTTP 和 HTTPS 均可使用。
3. 填写服务要求的鉴权信息：Bearer Token、Basic Auth，或 API Key / 自定义 Header。`X-API-Key` 是 Header 名称的一个例子，也可以使用自己网关要求的名称。
4. 点击「读取微信账号」。只有一个账号时自动选中；多个账号时选择要接入的账号，然后创建连接。
5. 加载会话，通过名称或 ID 搜索，按页浏览并勾选会话。跨页和搜索会保留勾选，最后点击「保存会话范围」。

agent-wechat 原生 API 使用 Bearer Token。Basic Auth 或自定义 API Key 需要你的反向代理支持，并将请求转换为上游接受的鉴权方式；仅在 Hast 选择一种鉴权方式不会改变服务端配置。

「修改服务连接设置」用于更新服务 URL 或访问凭证，不是微信扫码登录入口。

<h2 id="reconnect">断线与数据管理</h2>

微信退出后，回到运行 agent-wechat 的机器或 Docker 容器，通过原登录工具重新扫码并在手机确认。若服务由其他人维护，请联系维护者。Hast 会自动检测恢复，无需删除渠道。

如果服务不可访问，先检查进程、网络、地址和访问凭证；网络故障不一定表示微信已经退出。

对于「连接已有服务」，断开只停止 Hast 同步；删除渠道也不会删除你的 Docker 容器、数据卷或微信登录。已经同步的知识和附件默认保留，只有明确选择清理知识时才删除相应内容。备份和升级时保留服务数据卷及其凭证，避免误用删除卷的命令。

「待处理批次」表示上游仍有未完成的数据处理，不等于同等数量的聊天消息丢失。事件历史过期时 Hast 会回填仍可读取的历史；上游已经不再保存的数据无法保证补齐。
