Skill 用来保存一套可重复使用的工作方法。一个技能包可以包含入口文件和附属资料；在 Agent 配置中选中它后，Agent 才会使用这项技能。

<h2 id="create">创建技能</h2>

1. 打开 Skills，进入新建页面。
2. 填写目录名、显示名称和描述。
3. 编写入口文件，通常使用 `SKILL.md`。
4. 需要模板或参考资料时，加入附属文本文件。
5. 保存技能，回到 Agent 编辑页刷新资源目录，选中技能并保存 Agent。

下面是一份需求整理技能的示例内容：

```markdown
---
name: requirements-brief
description: 将用户提供的需求整理成可供评审的中文简报。
---

# 需求简报

保留用户给出的日期、数字和产品名称。
先概括目标，再列出约束和待确认问题。
未提供的信息写为“待确认”。
输出使用 Markdown，方便复制到项目文档。
```

<h2 id="import">导入已有技能</h2>

可以导入本地文件或目录，也可以从 GitHub 或 HTTPS 地址导入。导入本地文件会替换当前草稿的文件包，确认前先保存需要保留的内容。

检查入口文件、相对路径和附属文件是否齐全，再保存。每个文件必须为 UTF-8 文本，不超过 256 KiB；一个文件包总计不超过 1 MiB。

<h2 id="maintain">编辑、停用与删除</h2>

系统 Skill 只读。个人 Skill 可以编辑或停用；已创建的目录名不能修改。停用会影响当前 Profile 后续执行，Agent 表单不能新选一个已停用的个人 Skill。

保存编辑会提交完整文件包，因此不要把暂时没有加载到的附属文件当作可删除内容。页面提示内容已变化时，重新加载后再编辑。

删除被 Agent 引用的技能前，先从相关 Agent 的配置中移除并保存，再返回删除。
