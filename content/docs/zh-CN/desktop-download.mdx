HAST Desktop 以 macOS Universal 磁盘映像形式提供。请通过公开的发布索引查找当前稳定版；索引同时列出版本、文件大小和 SHA-256 校验和。

<h2 id="download">下载稳定版</h2>

打开 [HAST Desktop 发布索引](https://hast-desktop.fra1.digitaloceanspaces.com/releases.json)，选择 macOS（`darwin-universal`）稳定版条目。不要选择列在 prereleases 或 development 下的条目。打开该条目的安装包 URL，下载 `.dmg` 文件。

<h2 id="install">安装并启动 HAST Desktop</h2>

打开下载的磁盘映像，并按照 HAST Desktop 显示的 macOS 安装步骤操作。安装后启动应用；创建或打开项目之前，请先登录 HAST。使用工作区功能需要登录。

<h2 id="verify">核对版本信息</h2>

发布索引为每个下载项提供版本、SHA-256 校验和及字节大小。如需验证下载文件，请与同一稳定版条目中的值进行比较。当前安装包 URL 以发布索引为准；旧版本链接可能不是最新版本。
