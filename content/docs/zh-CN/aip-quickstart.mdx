这个例子创建一个“需求整理助手”：接收一段需求，把已知信息和待确认问题分开列出。先用纯文本跑通对话，再增加业务工具。

<h2 id="prepare">开始前</h2>

登录 AIP，确认头像菜单中的 Profile。你需要能打开 Agent 列表，并能加载可用模型。

<Steps titleSize="h2">

<Step title="创建并保存" id="create" stepNumber={1}>

1. 在 Agent 列表进入新建页面。
2. 名称填写“需求整理助手”，描述填写“整理需求中的目标、约束和待确认事项”。
3. 在系统提示词中填入下面的内容。
4. 从模型列表选择一个可用模型；如果显示推理强度，按任务需要选择。
5. 将调用状态设为启用。这个例子无需添加业务工具和机密。
6. 保存 Agent，确认进入详情页。

```text
你负责整理用户提供的需求。
先用一段话概括目标，再列出已明确的约束和待确认的问题。
保留原文中的数字、日期和名称。
没有提供的信息标记为“待确认”，不要补充假设作为事实。
使用中文回答。
```

</Step>

<Step title="发送测试消息" id="test" stepNumber={2}>

从详情页进入调试，确认选中刚创建的 Agent，创建调试会话并发送：

```text
我们要为客户做一个订单查询助手，客服会在聊天中输入订单号。
希望本月完成第一版，先支持查询状态，不需要修改订单。
请整理这段需求。
```

检查回复是否保留“本月”“只查询状态”等条件，是否把缺少的接口信息列为待确认。继续发送“把待确认问题按优先级排序”，检查对话是否沿用上文。

</Step>

</Steps>
