<h2 id="generate">生成草稿</h2>

在 Agents Feed 发起 `Run X Agent`。任务依据项目背景生成五条不同风格的帖子，完成后显示在 Feed 中。

也可以在 Growth Agent 中要求运行 X Agent，并明确让它把结果保存到 Agents Feed。

<h2 id="review">审阅内容</h2>

逐条检查功能描述、数字、链接和语气。点击 `Preview` 打开帖子预览，检查篇幅是否适合发布。

预览中的互动数字是展示效果，不是实际帖子表现。实际发布与互动情况需要到 X 查看。

<h2 id="publish">到 X 发布</h2>

点击 `Open composer`，在新标签页打开 X 编辑器。核对当前 X 账号，修改需要调整的内容，然后在 X 中完成发布。

<Note>

打开编辑器不等于已发布。回到 GTM 后，只有确实已经处理完的草稿才点击 `Mark sent`。这个按钮记录处理状态，并把草稿从待处理列表移除，不会代替你发送帖子。

</Note>
