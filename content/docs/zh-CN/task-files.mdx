<h2 id="upload">上传输入文件</h2>

在输入框旁点击上传按钮，选择文件并等待上传完成。单个文件不超过 10 MiB，一次最多添加 10 个文件。发送前可以移除选错的附件。

在消息中说明文件用途。例如：“使用 sales.csv 汇总收入，使用 regions.csv 补齐地区名称。”上传成功不代表已经开始处理，还需要发送任务并完成执行确认。

<h2 id="view">查看生成文件</h2>

有两个入口：侧栏中的“文件”，以及对话菜单中的“查看聊天中文件”。查某次任务时，优先从该对话进入，避免在其他工作区里寻找。

文件页支持搜索、进入目录和预览。无法预览的格式可以下载原始文件。刚完成任务但列表还为空时，刷新后再检查；同时确认 Agent 确实保存了文件，而不只是把内容写在回复里。

<h2 id="download">下载结果</h2>

可以下载单个文件，也可以在文件页使用“下载全部 ZIP”。下载后打开文件，检查内容和格式是否符合要求。

<h2 id="delete">删除文件</h2>

删除文件会永久移除该文件；删除目录会同时移除其内容。删除前确认已经保存所需副本。

通过程序管理文件时，在 AIP 创建具有文件权限的 Profile API key；上传和下载还需要接口返回的文件标识，见 [AIP API 文件操作](aip-api-reference#files)。
