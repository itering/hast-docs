<h3 id="v1-4-6">v1.4.6</h3>

**2026年11月25日 13:58（北京时间，正式发布）**

本次更新让知识库恢复更有针对性、消息渠道更稳定，打开对话和查看报告也更快。

**新特性**

- 个人微信支持同步全部会话，自动包含新会话，仍为只读同步。
- 共享应用获得“全部工具”授权及必要的组织审批后，可直接调用应用 API。

**体验优化**

- 知识库按来源显示处理状态，分别提示附件、导入、网页抓取和索引问题。
- 可从工作记录打开对应的 CRM 读取结果，核对答案来源。
- 视频编辑增加未保存更改保护，改进键盘操作反馈。

**问题修复**

- Slack 查询头像被限流时，回复仍可继续发送。
- 修复知识入库与 Wiki 发布卡住后的恢复，重试限定到所选来源。
- 同一企业下的微信客服共用回调域名，减少新增客服的接入冲突。
- 组织订阅前选好的扣款用卡能够正确保存。
- 保存 Agent 后立即试用，会使用刚保存的版本。

**性能提升**

- Agent 目录、运行报告和账单页减少启动等待。
- 打开或恢复对话时，更早显示已有消息。

**升级注意**

- 付费重跑前，核对具体条目及可能的重复费用，再逐项确认。
- 授权变更后若任务提示访问失效，请检查执行设置、保存后再运行。
- 为已接入的企业微信应用新增客服时，保留原回调地址。
