<h2 id="enable">启用记忆能力</h2>

在 Agent 配置中开启“长期记忆”，然后选择读取范围和写入位置并保存。单独创建记忆条目不会自动开启 Agent 的记忆能力。

<h2 id="scope">选择记忆范围</h2>

| 读取范围 | 可读内容 |
| --- | --- |
| `self` | 当前 Agent 自己的记忆 |
| `webhook` | 当前 Profile 下各 Webhook 的记忆和共享记忆 |
| `all` | 在 Webhook 范围之外，包含当前 Profile 的 Task Agent 记忆 |

写入位置为 `self` 或 `shared`。共享写入需要读取范围为 `webhook` 或 `all`。把读取范围改为 `self` 时，表单也会把写入位置改为 `self`。

新建 Agent 默认使用自身读取和自身写入。编辑已有 Agent 时应检查界面显示的范围，尤其是已有较宽读取范围的配置。

<h2 id="manage">维护记忆条目</h2>

打开记忆页面，按 Task Agent、Webhook 共享或具体 Agent 筛选。创建时填写名称和内容；例如保存客户希望使用的术语、报告格式或长期约束。

名称不超过 128 字，内容不能为空且不超过 256 KiB。同一归属中的名称应唯一。新 Agent 需要先保存，才能为它创建专属记忆。

可以编辑内容或迁移归属。变更影响后续读取，已经运行的任务不会自动重新加载上下文。Agent 删除后留存的记忆仍可迁移或删除。
