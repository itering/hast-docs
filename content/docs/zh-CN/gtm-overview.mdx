Hast GTM 是 Hast AIP 下用于市场与增长工作的产品子模块。它从一个网站建立项目，让调研、GEO、技术分析和内容任务使用同一份公司与产品背景。

输入网站后，系统读取站点资料，整理公司与产品信息，并提供性能、SEO、AI 品牌提及和流量分析。你也可以生成 X 帖子和文章草稿。

<h2 id="uses">适合哪些市场工作</h2>

网站上线后，团队往往需要先弄清产品如何被理解、网站有哪些问题，再决定要补充什么内容。GTM 将这些工作放在同一个项目里，便于结合分析结果安排下一步。

- 梳理公司定位、目标客户和竞品信息，为后续调研与写作准备背景。
- 检查搜索、网站性能与 AI 品牌提及，了解哪些地方值得继续分析。
- 基于项目资料准备文章和社交帖子，审阅后用于自己的营销渠道。

<h2 id="context">让调研和内容使用同一份背景</h2>

项目资料包含网站信息、公司画像和相关文档。分析与内容任务可以使用这些上下文，减少每次重新说明产品、受众和品牌语气的工作。

项目初始化后，先检查资料是否符合实际业务。产品定位或网站内容发生变化时，刷新项目上下文，再生成新的分析和草稿。操作见 [管理项目与网站资料](gtm-projects) 和 [公司分析与项目文档](gtm-company)。

<h2 id="workspace">项目里有什么</h2>

| 区域或能力 | 用途 |
| --- | --- |
| 公司与网站资料 | 查看产品信息、品牌语气、竞品和营销文档 |
| SEO 与 Performance | 查看 PageSpeed 检查结果及移动端、桌面端差异 |
| GEO | 查看买家问题和模型回答中的品牌提及 |
| Traffic | 授权 Google Analytics 后查看项目流量 |
| Agents Feed | 审阅 X 帖子和文章草稿 |
| Growth Agent | 用对话查询项目情况或发起支持的项目操作 |
| Run activity | 查看后台任务的状态和事件 |

<h2 id="start">从网站项目开始</h2>

先按 [快速开始](gtm-quickstart) 创建一个项目。初始化完成后检查网站和公司信息是否准确，再运行内容任务。

需要更新网站资料时重新运行 setup。新的分析与内容输出需要等待对应后台任务完成；排队成功不代表已经生成结果。

<h2 id="workflow">从分析结果安排下一步</h2>

1. 检查项目资料，确认公司、产品和受众信息。
2. 根据当前问题选择分析：网站速度和 SEO 看 [Performance](gtm-performance)，AI 回答中的品牌提及看 [GEO](gtm-geo)，网站访问情况看 [Traffic](gtm-traffic)。
3. 结合发现的问题生成 [文章草稿](gtm-articles) 或 [X 帖子](gtm-x)，核对事实、链接和品牌表达。
4. 发布内容或修改网站后，在后续分析中检查变化。

Traffic 需要先连接 Google Analytics。内容生成后仍需审阅，X 草稿通过页面提供的入口到 X 完成发布。PageSpeed 分析提供检查结果，网站修改需要在自己的网站项目中完成。

<h2 id="agent">通过 Growth Agent 操作项目</h2>

需要边看资料边安排工作时，可以使用项目内的 [Growth Agent](gtm-growth-agent)。它支持围绕项目提问，并发起已支持的上下文刷新、分析或内容操作。后台任务的进度和结果在运行记录中查看。

更多产品介绍见 [Hast GTM 产品页](https://hast.so/zh-CN/gtm)。
