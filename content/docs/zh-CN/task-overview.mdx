Hast Agent 是面向完整任务的 AI 工作区，本文档以 Task Agent 介绍它的任务入口。它围绕目标组织计划、工具调用、执行过程和交付文件，适合需要多个步骤、并根据结果继续调整的工作。

你描述目标和要求，Agent 开始执行并展示工作进展；后续可以继续追问、调整要求，或下载生成的文件。

<h2 id="uses">适合哪些工作</h2>

| 场景 | 可以交给 Agent 的工作 | 检查结果时关注什么 |
| --- | --- | --- |
| 市场与竞品研究 | 收集资料、比较方案、整理研究简报 | 来源、时间范围与结论依据 |
| 数据分析 | 整理表格、比较指标、生成分析说明 | 数据口径、计算过程与异常值 |
| 内容与资料整理 | 汇总文档、撰写报告、按反馈修订 | 信息完整性、读者与输出格式 |
| 开发与运营 | 在可用工具和权限范围内处理代码、浏览器或周期任务 | 实际执行结果与需要人工处理的事项 |

输入中写清资料来源、处理范围和结果格式。例如，可以要求“根据这些资料比较三种方案，输出优缺点表，并列出仍需核实的问题”。

<h2 id="workspace">在同一个工作区中持续推进</h2>

任务的回复与文件保留在工作区中。你可以查看执行过程，在原对话中要求补充或修订，并下载最终产物。上传资料和管理产物的操作见 [文件指南](task-files)。

Agent 可以结合代码、联网搜索、浏览器和连接器处理任务。外部应用需要先授权，可用连接器以工作区页面为准，操作见 [连接器与设置能力](task-capabilities)。

<h2 id="continuity">复用背景与安排重复工作</h2>

把项目背景、业务规则和团队偏好保存在记忆中，可以减少新任务中的重复说明。记忆需要由你查看和维护；临时要求仍可在当前对话中补充。

日报、资料汇总等周期工作可以设为 [定时任务](task-schedules)。设置任务要求、运行周期和时区后，查看每次运行的状态与结果，并根据实际输出调整要求。

<h2 id="workflow">一次任务如何完成</h2>

1. 在新对话中填写需求，按需上传文件。
2. 发送后查看执行进展，补充缺少的信息。
3. 查看回复和文件，确认结果是否符合要求。
4. 在同一对话中要求修订，或为新的工作创建对话。

先跟随 [快速开始](task-quickstart) 完成一次资料整理。需要周期运行时使用 [定时任务](task-schedules)。

<h2 id="api">程序接入</h2>

程序接入在 AIP 中管理，见 [AIP API 入门](aip-api-quickstart)。可以调用已保存的 AIP Agent，或使用 Profile API 密钥提交普通任务；两类接口使用不同的会话范围，普通任务 API 列表不会合并网页中的全部历史对话。

<h2 id="next">开始使用</h2>

第一次使用时，选一项输入资料齐全、结果容易检查的工作，跟随 [完成第一个任务](task-quickstart) 操作。已有明确集成需求，可以直接阅读 [AIP API 入门](aip-api-quickstart)。套餐与用量说明见 [套餐与用量](billing)。

更多产品场景见 [Hast Agent 产品页](https://hast.so/zh-CN/agent)。
