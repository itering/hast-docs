<h2 id="import">导入配置</h2>

在配置编辑器导入 AIP 模板或兼容的 Hook JSON。先查看导入预览，再确认替换当前草稿，最后保存。

导入时会检查当前 Profile 的技能和知识库。不存在或不可用的资源会从选择中移除，并在预览中提示。资源目录加载失败时，先重试加载再导入。

<h2 id="copy">复制已有 Agent</h2>

在详情页选择“复制为新 Agent”，检查复制后的草稿，调整名称和需要独立维护的配置，然后创建。新 Agent 有独立的调用入口；原 Agent 不会跟随副本修改。

<h2 id="export">导出与交接</h2>

导出不包含调用凭证、机密值或机密绑定。工具请求头的内嵌值及 URL 查询参数会替换为占位符，纯机密引用会保留。

导出后仍需检查提示词、描述、业务路径等自由文本是否适合分享。导入到另一个 Profile 后，重新选择资源，补齐机密绑定及占位符，再调试。

保留导出文件可以帮助人工恢复配置；产品没有自动配置回滚界面。
