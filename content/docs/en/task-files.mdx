<h2 id="upload">Upload inputs</h2>

Use the upload button beside the input, select files, and wait for completion. Each file can be up to 10 MiB, with up to 10 attachments at once. Remove incorrect attachments before sending.

Explain each file's purpose, for example: “Use sales.csv for revenue and regions.csv for region names.” Uploading does not start processing; send the task and confirm execution.

<h2 id="view">View generated files</h2>

Use Files in the sidebar or the conversation menu's file view. For a specific task, open files from that conversation to avoid searching a different workspace.

Search, open directories, and preview files. Download formats without previews. If the list is empty after a run, refresh and verify that the Agent saved a file rather than only writing content in its reply.

<h2 id="download">Download results</h2>

Download a single file or use the option to download all as ZIP. Open the downloaded files and verify their content and format.

<h2 id="delete">Delete files</h2>

Deleting a file permanently removes it; deleting a directory removes its contents too. Save any needed copies first.

For programmatic file access, create a Profile API key in AIP with file permissions. Upload and download also require the file identifiers returned by the API. See [AIP file endpoints](aip-api-reference#files).
