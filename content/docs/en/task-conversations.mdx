<h2 id="request">State the requirements</h2>

Describe the work and how you will assess it. Identify specific files, dates, and sources for web or app access.

```text
Analyze my uploaded sales spreadsheet, total revenue by month, and list records with missing amounts.
Do not treat missing values as zero. Produce a CSV and an English explanation.
```

<h2 id="execute">Check execution</h2>

The Agent starts work after you send the request. Inspect messages, work plans, tool activity, and status. You can add instructions. Before changing scope, check completed actions and stop the current work when necessary.

Preparing or queued means the task is waiting for execution conditions. If sending is temporarily unavailable, check run status instead of repeatedly submitting the same request.

<h2 id="stop">Stop and continue</h2>

Use Stop to interrupt work. Closing the page does not send a stop request. After status updates, explain the changed requirements in the same conversation and continue.

<Note>If completed actions wrote to an external system, check that system after stopping. Stopping does not undo completed operations.</Note>

<h2 id="history">Manage history</h2>

Reopen conversations from the recent list. Rename them through the action menu to organize by project or date; titles cannot be empty.

Deletion requires confirmation and cannot be undone through the UI. Download required outputs before deleting a conversation.
