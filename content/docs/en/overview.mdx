Hast connects private data, internal systems, and business processes so enterprises can use AI in daily work. Forward-Deployed Engineers (FDEs) help define use cases, connect systems, and deliver deployments. Reusable capabilities from this work become part of Hast AIP.

<h2 id="platform">Hast AIP: a platform for FDE delivery</h2>

Hast AIP is the platform and workbench built through FDE practice. It provides platform capabilities and team support: configure and debug Agents, manage knowledge, Skills, and business tools, and connect Agents to customer systems. Start with the [AIP workbench guide](aip-overview).

<h2 id="products">Two product modules</h2>

Hast AIP includes Hast Agent and Hast GTM.

| Module | Purpose | Guide |
| --- | --- | --- |
| Hast Agent | Work through research, content, development, and operations tasks in conversation; inspect execution and retrieve replies and files | [Task Agent](task-overview) |
| Hast GTM | Create website projects, run analysis, inspect brand visibility, and generate marketing drafts | [GTM](gtm-overview) |

In these docs, Task Agent refers to the task interface of Hast Agent. Its workflows and APIs are grouped under Task Agent in the sidebar.

<h2 id="fde">FDE: delivering with customers</h2>

FDE is the delivery team. It works with customers to define scenarios, connect enterprise data and systems, validate results, and launch. After launch, the team addresses issues and improves results. FDE uses Hast AIP; it is not a product module.

Enterprises can use Hast Agent or Hast GTM directly, or work with FDEs to integrate specific workflows into existing systems. See [FDE delivery](https://hast.so/en/fde).

<h2 id="integration">Programmatic access</h2>

An AIP Agent's detail page provides a credential-bearing URL for sending messages and receiving streamed replies from your server. See [AIP HTTP integration](aip-api).

AIP exposes public endpoints authenticated with API keys. To call saved Agents, read conversations, or manage business resources, start with the [AIP API quickstart](aip-api-quickstart). Each key's access range and permissions determine which endpoints it can use.
