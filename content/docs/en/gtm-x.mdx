<h2 id="generate">Generate drafts</h2>

Run `Run X Agent` in Agents Feed. It creates five posts in different styles from project context and displays them in the Feed when complete.

You can also ask Growth Agent to run X Agent and explicitly save results to Agents Feed.

<h2 id="review">Review the content</h2>

Check feature claims, numbers, links, and tone for each post. Open `Preview` and check its length for publication.

Engagement numbers in previews are illustrative, not actual post performance. Check publication and engagement on X itself.

<h2 id="publish">Publish on X</h2>

Choose `Open composer` to open X in a new tab. Verify the active X account, edit as needed, and publish there.

<Note>Opening the composer does not publish. Back in GTM, use `Mark sent` only after handling the draft. It records the handling state and removes the draft from the pending list; it does not send the post.</Note>
