<h2 id="prepare">Before you start</h2>

Prepare the site URL and verify the current Profile has an active plan and room within its project limit. This guide retains English button names used by GTM.

<Steps titleSize="h2">

<Step title="Create a project" id="create" stepNumber={1}>

1. Open the project list and start a new project.
2. Enter the domain or a page URL in `Website`.
3. Check the resolved URL shown below the field.
4. Optionally enter `Project name`.
5. Click `Create project`.

If disabled, inspect URL validation, plan, and project-limit messages.

</Step>

<Step title="Wait for initialization" id="setup" stepNumber={2}>

The initialization page shows stages such as reading the website, understanding the company, and preparing visibility analysis. Jobs have dependencies, so some wait for earlier data.

Watch progress instead of creating the same project again. Record failed tasks and errors and consult [troubleshooting](gtm-troubleshooting).

</Step>

<Step title="Check results" id="review" stepNumber={3}>

Check the company name, product description, URL, and sources first. Then inspect available PageSpeed, buyer-question, and AI mention results. Google Analytics requires separate authorization and a GA property selection.

For your first content task, try an [article draft](gtm-articles). Set the language and audience, verify product facts, then copy it into your publishing tool.

</Step>

</Steps>
