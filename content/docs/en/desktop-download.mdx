HAST Desktop is available as a macOS Universal disk image. Use the public release index to find the current stable download; it also lists the release version, file size, and SHA-256 checksum.

<h2 id="download">Download the stable release</h2>

Open the [HAST Desktop release index](https://hast-desktop.fra1.digitaloceanspaces.com/releases.json) and choose the stable macOS (`darwin-universal`) entry. Do not choose an entry listed under prereleases or development. Open the installer URL from that entry to download the `.dmg` file.

<h2 id="install">Install and start HAST Desktop</h2>

Open the downloaded disk image and follow the macOS installation steps shown for HAST Desktop. Launch the app after installation and sign in to HAST before creating or opening projects. The app requires sign-in for its workspace features.

<h2 id="verify">Check the release details</h2>

The release index identifies each download by version and provides its SHA-256 checksum and byte size. If you verify a download, compare it with the values in the same stable release entry. The index is the source for the current installer URL; older release links may no longer be the latest version.
