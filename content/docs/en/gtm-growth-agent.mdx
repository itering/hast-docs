<h2 id="ask">Ask about the current project</h2>

Open Growth Agent in the project workbench. It can read project context and call supported operations. Check the project name first.

```text
Review this project's company information. List the facts that affect article topics and the evidence still missing.
```

<h2 id="operations">Start operations in conversation</h2>

Supported operations include website setup, PageSpeed, company analysis, project documents, buyer questions, AI Mention, Google Analytics synchronization, X tasks, and article tasks.

```text
Run PageSpeed for mobile and desktop for this project.
```

```text
Run Article Agent to create an English how-to for developers and save it to Agents Feed.
```

<h2 id="status">Replies and background results</h2>

A “queued” reply means work was submitted. Check `Run activity` for completion, then open the corresponding report or Feed output.

You can follow up and view conversation history. Stopping the current conversational generation does not imply all queued project jobs were canceled; inspect those separately.
