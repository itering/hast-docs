<h2 id="configure">Set article requirements</h2>

Start `Run Article Agent` and configure the article:

| Setting | Options or guidance |
| --- | --- |
| Style | How-to, technical deep dive, comparison, problem and solution, data and opinion |
| Language | Automatic, English, or Chinese |
| Audience | Who will read it and what they already know |
| Funnel stage | Automatic, top, middle, or bottom |
| Topic | The specific question this article should answer |
| Target query | Search questions or keywords to cover |

For developers familiar with the product, choose an English how-to with a topic such as “Connect an order lookup assistant to a support system.”

<h2 id="generate">Wait for the draft</h2>

Inspect task status after submitting. Each run produces one long-form Markdown draft in Agents Feed.

Growth Agent can start article tasks too. Explicitly request Article Agent when you want Feed output, rather than only a conversational answer.

<h2 id="review">Review and reuse</h2>

Open the preview and check the title, product facts, data sources, and links. Copy Markdown into your content system and edit for the publishing platform.

<Note>A draft has not been published to your site. Verify unreleased features, customer stories, and performance figures before using them.</Note>
