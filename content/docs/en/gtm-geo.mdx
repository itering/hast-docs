<h2 id="prompts">Review buyer questions</h2>

Buyer prompt set generates five questions with intent and category. Check that they reflect target customers and relate to your product.

If missing, run `Run buyer prompts`. This set supplies the input to AI Mention analysis.

<h2 id="run">Run mention analysis</h2>

Choose `Run AI Mention`. GTM checks the questions against three configured models; actual model names appear in results.

Each model has its own task state. Waiting, queued, or running means its result is not yet complete.

<h2 id="read">Inspect answers</h2>

Read the question, complete answer, mention result, and matched terms. These metrics describe this question set and these model answers; they are not search rankings, market share, or sales conversion.

When questions, models, or site context change, note those differences in comparisons. Preserve the original questions and answers before assessing whether content changes relate to the results.
