<h2 id="switch">Switch and identify projects</h2>

Use the project switcher. Before analysis or content generation, check the project name and URL. Switch Profile first when looking for another identity's projects.

<h2 id="refresh">Refresh website context</h2>

After site changes, choose `Run setup` from the run menu or ask Growth Agent:

```text
Refresh this project's website context, reread pages and public site files, and tell me which jobs were queued.
```

Wait for setup to complete before checking updated sources. Some actions cannot be started again while already running.

<h2 id="files">Inspect site files</h2>

The project can display `llms.txt`, `robots.txt`, `sitemap.xml`, favicons, and fetched pages. Check HTTP status: 404 means that address did not return a file, not necessarily that the whole project failed.

These are fetched sources. Running setup does not modify your site's files.

<h2 id="settings">Rename and delete</h2>

Use project settings to rename or delete. Verify a new name in the switcher. Before deleting, save required reports and drafts and confirm the site's identity.
