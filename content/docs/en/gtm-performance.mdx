<h2 id="run">Run a check</h2>

Choose `Run PageSpeed` in the project run menu. GTM runs Performance and SEO checks for mobile and desktop. After background jobs finish, choose the report tab and device type in analysis.

<h2 id="read">Read the report</h2>

Check the report time and device, then scores, metrics, and failed audits. Performance helps identify loading, blocking, and layout issues; SEO lists issues found in that check.

Reports contain lab metrics and, when available, real-user data. Treat absent data as missing, not as a score of zero.

<h2 id="compare">Recheck after site changes</h2>

Fix issues in your website project, then rerun checks in GTM. Compare the same device type and note changes in test time and page content.

Reports help find and track issues. Running a check does not deploy fixes to your website.
