<h2 id="connect">Connect external apps</h2>

1. Open Connectors.
2. Find the app and choose Connect.
3. Check the account and permissions on its authorization page and finish authorization.
4. Return to Hast, refresh, and verify the connected state.

Specify the app, object, and action in your task. Availability follows the current catalog; Unavailable may mean authorization has not been configured for this deployment.

Check the app and account before confirming disconnection. Reconnect before later tasks that need the app.

<h2 id="memory">Save long-term memory</h2>

Create entries on the Memory page for reusable background, preferences, or constraints:

```text
Write reports in English. Preserve the original currency for amounts.
Do not invent numbers without sources; list missing data separately.
```

Save edits. Deleted entries are not injected into later runs, but editing memory does not automatically rewrite the context of tasks already running. Check ownership; Task Agent and scheduled tasks use the same kind of memory scope.

<h2 id="methods">Use built-in skill management</h2>

Skills in the capabilities area manage working methods for task execution. Open an entry to read `SKILL.md` and enable or disable it. Create personal Skills by supplying a name, description, and Markdown content.

<h2 id="account">Connect your Codex account</h2>

If the UI offers Codex account connection, start it, open the verification page, and enter the displayed device code. Return to Hast and check the connection state.

Reconnect when authorization expires. Availability, models, and allowances depend on the permissions and account state currently shown in the UI.
