Hast Agent はタスク全体を扱う AI ワークスペースです。このドキュメントではそのタスク画面を Task Agent と呼びます。目標に沿って計画、ツール呼び出し、実行、成果ファイルをまとめ、複数段階の作業や結果を見ながらの修正に適しています。

目標と要件を伝えると、Agent が実行を開始し、進捗を表示します。その後も追加質問、要件の変更、生成ファイルのダウンロードができます。

<h2 id="uses">適した作業</h2>

| 場面 | 依頼できる作業 | 確認する点 |
| --- | --- | --- |
| 市場・競合調査 | 資料収集、案の比較、調査概要 | 情報源、期間、結論の根拠 |
| データ分析 | 表の整理、指標比較、分析説明 | 定義、計算過程、外れ値 |
| 文書・コンテンツ | 要約、レポート作成、フィードバックに基づく修正 | 網羅性、読者、出力形式 |
| 開発・運用 | 利用可能な権限でコード、ブラウザ、定期作業を処理 | 実際の結果と人の対応が必要な事項 |

情報源、範囲、形式を指定します。例えば「この資料で 3 案を比較し、長所・短所の表と未確認事項を出力して」と依頼できます。

<h2 id="workspace">同じワークスペースで継続</h2>

回答とファイルはワークスペースに残ります。実行過程を確認し、元の会話で補足や修正を依頼して、最終成果物をダウンロードできます。[ファイルガイド](task-files)を参照してください。

コード、Web 検索、ブラウザ、接続済みアプリを使えます。外部アプリは事前認証が必要で、利用可能な接続先は画面で確認します。[アプリと機能](task-capabilities)をご覧ください。

<h2 id="continuity">背景の再利用と定期作業</h2>

プロジェクトの背景、業務ルール、チームの好みをメモリに保存すると説明の繰り返しを減らせます。内容は自分で確認・管理し、一時的な要件は会話に追加します。

日報や定期集計には[スケジュール](task-schedules)を使います。指示、周期、タイムゾーンを設定し、各実行の結果に合わせて要件を調整します。

<h2 id="workflow">タスクの流れ</h2>

1. 新しい会話に要件を入力し、必要ならファイルを添付します。
2. 進捗を確認し、不足情報を補います。
3. 回答とファイルが要件を満たすか確認します。
4. 同じ会話で修正を依頼するか、別の作業は新しい会話を作ります。

[クイックスタート](task-quickstart)で資料整理を試せます。定期実行は[スケジュール](task-schedules)を参照してください。

<h2 id="api">プログラムからの利用</h2>

プログラムからのアクセスは AIP で管理します。[AIP API クイックスタート](aip-api-quickstart)を参照してください。保存済み AIP Agent の呼び出し、または Profile API key による通常タスクの送信が可能です。両者の会話範囲は異なり、通常タスク API の一覧には Web の全会話履歴は含まれません。

<h2 id="next">利用を始める</h2>

入力が揃い、結果を確認しやすい作業を選び、[最初のタスク](task-quickstart)を試してください。接続要件が明確なら [AIP API クイックスタート](aip-api-quickstart)へ進めます。[プランと使用量](billing)、[製品紹介](https://hast.so/ja/agent)も参照してください。
