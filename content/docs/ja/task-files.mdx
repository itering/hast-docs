<h2 id="upload">入力ファイルをアップロード</h2>

入力欄の横のボタンからファイルを選び、完了を待ちます。1 ファイル 10 MiB 以下、一度に最大 10 個です。送信前に誤った添付を外せます。

「sales.csv で売上を集計し、regions.csv で地域名を補って」など用途を伝えます。アップロードだけでは処理は始まらず、依頼の送信と実行確認が必要です。

<h2 id="view">生成ファイルを閲覧</h2>

サイドバーのファイル画面、または会話メニューの会話内ファイルから開けます。特定タスクのファイルはその会話から開くと、別ワークスペースとの混同を避けられます。

検索、ディレクトリ移動、プレビューが可能です。プレビュー非対応形式は原本をダウンロードします。実行直後に空なら更新し、Agent が回答に書いただけでなくファイルを保存したか確認してください。

<h2 id="download">結果を取得</h2>

個別にダウンロードするか、全ファイルの ZIP ダウンロードを使います。取得後に開き、内容と形式を確認します。

<h2 id="delete">ファイルを削除</h2>

ファイルは完全に削除され、ディレクトリ削除では中身も消えます。必要なコピーを先に保存してください。

プログラムからファイルを操作するには、AIP でファイル権限を持つ Profile API key を作成します。アップロード・ダウンロードには API が返すファイル ID も必要です。[AIP ファイル API](aip-api-reference#files)を参照してください。
