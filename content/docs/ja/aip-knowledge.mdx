ナレッジベースは、Agent が使う複数のソースをまとめます。原資料、検索索引、整理されたナレッジは別々に保持されます。操作前に現在の Profile とナレッジベースを確認してください。

<h2 id="create">資料を追加</h2>

1. ナレッジベースを作成し、名前と説明を入力します。
2. ファイルや公開 URL を追加するか、資料ライブラリの既存ソースを関連付けます。URL は HTTPS を使用し、アカウント認証情報を含めないでください。
3. 直接アップロードできるのは、空ではない 10 MiB 以下のファイルです。このフォームは動画を受け付けません。Google Drive を同期する場合は、先にアカウントを接続し、Drive ソースとルートフォルダーを選びます。
4. 送信後、ソース処理と索引の状態を確認します。受付済みでも、資料が検索可能になったとは限りません。失敗した場合はソースとエラーを確認し、画面の再試行操作を使います。

ソース処理、索引、ナレッジ整理には、それぞれの状態があります。状態を取得できないときは読み込みを再試行し、資料が空、または処理済みと判断しないでください。

<h2 id="use">Agent で利用</h2>

Agent 編集画面で一覧を更新し、必要なナレッジベースを選んで保存します。資料内に答えがある質問と、資料が扱っていない質問でデバッグし、回答と参照を確認します。

ナレッジ整理を有効にすると、完了後に Wiki とエンティティの関係を確認できます。整理されたページは派生結果です。内容を確認するときは参照から原資料を開いてください。生成されたページはソースの証拠に代わるものではありません。

<h2 id="update">ソースと結果を管理</h2>

同じナレッジベースでソースを追加・解除できます。資料を変更するたびに新しいベースを作る必要はありません。ベースからソースを解除しても、原資料は資料ライブラリに残ります。

名前や説明の変更は保存してください。ソース変更後は索引とナレッジ整理の状態を確認し、画面の操作で失敗した処理を再試行するか、索引を再構築します。整理結果の消去とソースの解除は別の操作です。実行前に影響の説明を確認してください。

ベースの変更・削除前には、利用中の Agent を確認します。同時編集でバージョン競合が表示された場合は、現在の内容を読み直してから変更を送信してください。
