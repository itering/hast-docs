ナレッジベースは、Agent が使う複数のソースをまとめます。原資料、検索索引、整理されたナレッジは別々に保持されます。操作前に現在の Profile とナレッジベースを確認してください。

<h2 id="create">資料を追加</h2>

1. ナレッジベースを作成し、名前と説明を入力します。
2. ファイルや公開 URL を追加するか、資料ライブラリの既存ソースを関連付けます。URL は HTTPS を使用し、アカウント認証情報を含めないでください。
3. 直接アップロードできるのは、空ではない 10 MiB 以下のファイルです。このフォームは動画を受け付けません。Google Drive を同期する場合は、先にアカウントを接続し、Drive ソースとルートフォルダーを選びます。
4. 送信後、ソース処理と索引の状態を確認します。受付済みでも、資料が検索可能になったとは限りません。失敗した場合はソース、表示された処理段階、エラーを確認し、画面に再試行操作がある場合だけ使用します。

<h2 id="processing-status">処理状態を確認</h2>

項目の詳細を開き、表示された段階に応じて対応します。**原本を取得できません** は添付ファイル自体が利用できない状態です。**原本は保存済みですが、内容を処理できません** は原本が残っていて抽出に失敗した状態で、前者とは異なります。**検索索引の作成に失敗** は索引の問題です。**処理枠を待機中** は処理がまだ進んでいない状態です。抽出は既定で、初回を含めて項目ごとに最大 5 回まで試行します。試行回数の上限に達した場合は、現在の状態とエラーを確認し、画面に再試行操作がある場合だけ使用してください。プロバイダーの処理が完了しているのに結果が保存されていない場合、別の有料試行には所有者の明示的な承認が必要です。使用料の精算は会計処理であり、再実行の承認にはなりません。結果が未確認の項目を失敗と決めつけたり、自動で再試行したりしないでください。添付ファイルが上流で利用できなくなった場合、ナレッジから復元することはできません。

状態のリクエストでは `page` と `source_id` で絞り込みでき、1 ページあたり最大 50 件が返ります。`source_id` を指定すると、1 つのソースに絞って確認できます。レスポンスには各ソースの状態が含まれ、添付ファイルを利用できないソースは `attachment_sources` に一覧表示されます。項目ごとに利用可能な `retry_target` に従ってください。索引の再試行は指定したソースだけに適用されます。有料の再実行が提示された場合は、その項目に表示された正確な `replay_attempt_id` だけを確認に使用してください。試行 ID を別の項目に再利用したり、同じ ID で再実行を繰り返したりしないでください。

ソース処理、索引、ナレッジ整理には、それぞれの状態があります。状態を取得できないときは読み込みを再試行し、資料が空、または処理済みと判断しないでください。

PDF ではスキャンしたページから文字が抽出される場合があります。検索結果を使う前にソース処理と索引の状態を確認し、重要な箇所は原本と照合してください。原本が保持されていると表示される場合は、原本を開く操作を使えます。パスワード保護された PDF は AIP でプレビューできないことがあります。再試行するのではなく、ダウンロードして PDF リーダーで開いてください。処理や状態の読み込みが中断された場合は、ソースを開き直して現在の状態を確認してから再試行します。アップロード受付や一部の結果だけでは、全ページが検索可能とは限りません。

<h2 id="use">Agent で利用</h2>

Agent 編集画面で一覧を更新し、必要なナレッジベースを選んで保存します。資料内に答えがある質問と、資料が扱っていない質問でデバッグし、回答と参照を確認します。

ナレッジ整理を有効にすると、完了後に Wiki とエンティティの関係を確認できます。整理されたページは派生結果です。内容を確認するときは参照から原資料を開いてください。生成されたページはソースの証拠に代わるものではありません。

<h2 id="update">ソースと結果を管理</h2>

同じナレッジベースでソースを追加・解除できます。資料を変更するたびに新しいベースを作る必要はありません。ベースからソースを解除しても、原資料は資料ライブラリに残ります。

ナレッジ整理が有効で、更新が保留中でない場合は **今すぐ更新** を使えることがあります。現在のベースの更新を依頼する操作です。ページがすぐに準備できるとは限らないため、整理の状態を確認してください。Wiki の公開時には構築に使ったソースが確認されますが、個々のページの参照を開くには引き続きソースへのアクセスが必要です。

名前や説明の変更は保存してください。ソース変更後は索引とナレッジ整理の状態を確認し、画面の操作で失敗した処理を再試行するか、索引を再構築します。整理結果の消去とソースの解除は別の操作です。実行前に影響の説明を確認してください。

ベースの変更・削除前には、利用中の Agent を確認します。同時編集でバージョン競合が表示された場合は、現在の内容を読み直してから変更を送信してください。
