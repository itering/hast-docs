<h3 id="v1-4-6">v1.4.6</h3>

**2026年11月25日 13:58（北京時間、UTC+8・正式リリース）**

今回の更新では、ナレッジベースの復旧対象を絞り込み、メッセージチャネルの安定性を改善しました。会話やレポートの表示も高速化しています。

**新機能**

- 個人用 WeChat で全会話の同期に対応し、新しい会話も自動的に同期対象に含まれます。引き続き読み取り専用の同期です。
- 共有アプリは、「すべてのツール」の権限と必要な組織の承認を取得すると、アプリ API を直接呼び出せます。

**使いやすさの改善**

- ナレッジベースでソースごとの処理状況を表示し、添付ファイル、インポート、Web クロール、インデックスの問題を個別に案内します。
- 作業記録から対応する CRM の読み取り結果を開き、回答の情報源を確認できます。
- 動画編集で未保存の変更を保護し、キーボード操作のフィードバックを改善しました。

**不具合修正**

- Slack のアバター取得がレート制限されても、返信の送信を継続できます。
- ナレッジ取り込みや Wiki 公開が停止した場合の復旧を修正しました。再試行は選択したソースに限定されます。
- 同一企業内の WeChat カスタマーサービスでコールバックドメインを共有し、アカウント追加時の接続競合を減らしました。
- 組織のサブスクリプション契約前に選択した支払いカードが正しく保存されます。
- Agent の保存直後に試用すると、保存したばかりのバージョンが使用されます。

**パフォーマンス**

- Agent ディレクトリ、実行レポート、請求ページの初期表示までの待ち時間を短縮しました。
- 会話を開く際や再開する際に、既存のメッセージをより早く表示します。

**アップグレード時の注意**

- 有料の再実行前に、対象項目と重複請求の可能性を確認し、項目ごとに承認してください。
- 権限変更後にタスクでアクセス無効と表示された場合は、実行設定を確認し、保存してから再実行してください。
- 接続済みの WeCom アプリにカスタマーサービスを追加する際は、既存のコールバック URL を維持してください。
