<h2 id="intelligence">会社分析を確認</h2>

Project intelligence は製品、顧客、価格、SNS アカウント、競合情報を整理します。サイト更新後に分析を再実行し、情報源と実際の業務が一致するか確認します。

<h2 id="documents">文書を閲覧</h2>

最新の会社分析から、次の 4 種類の Markdown 文書を生成します。

| 文書 | 内容 |
| --- | --- |
| Product Information | 製品情報 |
| Brand Voice | ブランド表現 |
| Competitor Analysis | 競合分析 |
| Marketing Strategy | マーケティング戦略 |

開いて本文を読み、再利用する場合は Markdown をコピーします。文書がなければ会社分析を先に実行してから生成します。

<h2 id="review">生成前に事実を確認</h2>

製品名、機能範囲、対象顧客、価格を確認します。生成分析には推測が含まれる場合があるため、公開記事や投稿に使う前に実際の製品と照合してください。

根拠を更新するにはサイトと会社分析を更新し、影響する文書や原稿を再生成します。古い原稿の生成日時を最新資料の日時として扱わないでください。
