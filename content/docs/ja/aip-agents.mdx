<h2 id="edit">設定を編集</h2>

Agent 一覧から詳細を開き、編集に進みます。フォームと JSON モードは同じ下書きを編集し、保存すると反映されます。

| 設定 | 入力の目安 |
| --- | --- |
| 名前と説明 | 一覧やデバッグで探しやすいよう担当業務を記載 |
| システムプロンプト | 入力、処理方法、追加情報を求める条件、出力を指定 |
| モデルと推論強度 | カタログの選択肢を使用。対応する強度はモデルによって異なる |
| 呼び出し状態 | 外部からの呼び出しを有効・無効にする |
| サンドボックス権限 | ファイル書き込みや操作の必要性に応じて選択 |
| Skills | 必要な作業方法を選択 |
| ナレッジベース | 索引化済みの資料を選択 |
| ポリシー | 検索や長期メモリなど必要な機能を有効化 |

リソース一覧の読み込みに失敗したら再試行します。更新しても下書きは保持されます。ナレッジベースを追加するとフォームで検索機能が有効になりますが、他の機能は個別に確認してください。

CRM やシークレットが不足する場合は「新しいタブで設定」を使います。元の Agent 編集タブを開いたまま設定し、戻って CRM またはシークレットの一覧を更新してから選択します。更新はリソース参照のみで、名前・用途・詳細設定の下書きを置き換えません。元のタブを閉じたり再読み込みしたりすると、未保存内容が失われる場合があります。

モデル選びに迷う場合は Auto を利用できます。候補、デフォルト、課金方法は [Auto を選ぶ](task-capabilities#auto-model)を参照してください。

<h2 id="assistant">設定アシスタントを使う</h2>

ワークスペースで利用できる場合は、設定アシスタントに Agent や関連リソースの変更を依頼できます。権限モードは会話ごとに設定します。

- **承認を待つ**：重要な変更には承認が必要です。承認前に保留中の変更を確認し、実行後に結果を確認してください。
- **フルアクセス**：この会話では管理権限のあるリソースを直接変更・削除・実行できます。必要な場合だけ選択してください。削除したリソースをアシスタントで復元することはできません。

シークレット値はチャットに入力せず、安全な入力フォームを使います。アシスタントは保存済み設定を変更し、編集画面の未保存の下書きは使いません。完了後に編集画面を再読み込みして下書きを確認し、新しいデバッグセッションで結果を確認してください。

<h2 id="save">保存と共同編集</h2>

保存すると現在の設定が更新されます。設定の履歴やロールバック画面はなく、同時編集では最後に成功した保存が適用されます。重要なプロンプトやツールを変更する前に設定をエクスポートしてください。

未保存の編集画面から離れるときは、案内に従って編集を続けるか破棄します。保存後は新しいデバッグセッションで結果を確認します。

<h2 id="disable">無効化と削除</h2>

一時的に呼び出しを受け付けない場合は Agent を無効にします。削除前に業務サービスが呼び出し URL を使っていないことを確認し、必要な設定やメモリを保存します。

サービスの起動処理が設定を同期する場合、コンソールの変更が次回同期で上書きされる可能性があります。変更元をサービスの管理者と確認してください。
