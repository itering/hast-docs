<h2 id="generate">下書きを生成</h2>

Agents Feed で `Run X Agent` を実行します。プロジェクト背景から異なるスタイルの投稿を 5 件生成し、完了後に Feed に表示します。

Growth Agent に X Agent の実行を依頼し、Agents Feed へ保存するよう明示することもできます。

<h2 id="review">内容をレビュー</h2>

機能説明、数値、リンク、文体を確認します。`Preview` で表示を開き、公開に適した長さか確認してください。

プレビューの反応数は表示例で、実際の投稿実績ではありません。公開状態と反応は X で確認します。

<h2 id="publish">X で公開</h2>

`Open composer` で新しいタブに X を開きます。アカウントを確認し、必要な編集をして X で公開します。

<Note>編集画面を開くだけでは公開されません。GTM に戻ったら、処理済みの原稿だけを `Mark sent` にします。これは処理状態を記録して未処理一覧から外す操作であり、投稿の送信は行いません。</Note>
