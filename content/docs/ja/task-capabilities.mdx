<h2 id="connect">外部アプリを接続</h2>

1. コネクターを開きます。
2. 必要なアプリを探し、接続を選びます。
3. 認証画面でアカウントと権限を確認して認証します。
4. Hast に戻り、更新して接続済みを確認します。

依頼ではアプリ、対象、操作を指定します。利用可否は現在のカタログに従い、Unavailable はこの環境で認証設定が未完了の可能性があります。

切断時はアプリとアカウントを確認してください。後続タスクで必要になったら再接続します。

<h2 id="memory">長期メモリを保存</h2>

メモリ画面で、タスクをまたいで使う背景、好み、制約を保存します。

```text
レポートは日本語で書き、金額の通貨は原文のまま保持してください。
出典のない数値は補わず、不足データを別に列挙してください。
```

編集後は保存します。削除した項目は後続実行に渡されませんが、実行中の文脈が自動的に書き換わるわけではありません。所有先も確認してください。Task Agent とスケジュールは同種のメモリ範囲を使います。

<h2 id="methods">製品内のスキル管理</h2>

機能エリアの Skills で実行時の作業方法を管理します。項目を開くと `SKILL.md` を確認し、有効・無効を切り替えられます。個人 Skill は名前、説明、Markdown 本文を入力して作成します。

<h2 id="account">自分の Codex アカウントを接続</h2>

画面に接続入口がある場合は開始し、確認ページで表示されたデバイスコードを入力します。完了後 Hast に戻り、状態を確認します。

認証期限が切れたら再接続します。接続可否、モデル、利用枠は画面の権限とアカウント状態によって異なります。
