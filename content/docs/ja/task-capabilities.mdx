<h2 id="connect">外部アプリを接続</h2>

1. コネクターを開きます。
2. 必要なアプリを探し、接続を選びます。
3. 認証画面でアカウントと権限を確認して認証します。
4. Hast に戻り、更新して接続済みを確認します。

依頼ではアプリ、対象、操作を指定します。利用可否は現在のカタログに従い、Unavailable はこの環境で認証設定が未完了の可能性があります。

切断時はアプリとアカウントを確認してください。後続タスクで必要になったら再接続します。

<h2 id="memory">長期メモリを保存</h2>

メモリ画面で、タスクをまたいで使う背景、好み、制約を保存します。

```text
レポートは日本語で書き、金額の通貨は原文のまま保持してください。
出典のない数値は補わず、不足データを別に列挙してください。
```

編集後は保存します。削除した項目は後続実行に渡されませんが、実行中の文脈が自動的に書き換わるわけではありません。所有先も確認してください。Task Agent とスケジュールは同種のメモリ範囲を使います。

<h2 id="methods">製品内のスキル管理</h2>

機能エリアの Skills で実行時の作業方法を管理します。項目を開くと `SKILL.md` を確認し、有効・無効を切り替えられます。個人 Skill は名前、説明、Markdown 本文を入力して作成します。

<h2 id="port-sharing">一時的な Web プレビューを共有</h2>

一時的なポート共有が有効な環境では、Sandbox 内で動作する Web ページや API の共有を Agent に依頼できます。HTTP、WebSocket、SSE に対応しています。例：「このプロジェクトの Web サーバーを起動し、5分間有効なリンクを共有してください」。リンクを作成する前に、サービスが起動している必要があります。

完全なリンクを持つ人は、Hast にログインせずにサービスへアクセスできます。`#` 以降を含むリンク全体を開き、共有する相手を確認してください。アクセスしても Sandbox の稼働は延長されず、一時停止中の Sandbox は起動しません。

作成時に有効期間を指定する必要があり、最長10分です。期限切れ、取り消し、Sandbox の一時停止、アイドル回収、再起動でリンクは永久に無効になります。再開しても再利用できません。引き続き必要な場合は、必要に応じてサービスを起動し直し、新しいリンクを作成するよう Agent に依頼してください。

Agent が Sandbox 内で Helper を使う場合、次のコマンドでリンクを作成、確認、取り消しできます。

```sh
hast-helper port-forward create '{"port":3000,"ttl_seconds":300}'
hast-helper port-forward list '{}'
hast-helper port-forward revoke '{"id":"<forward-id>"}'
```

`ttl_seconds` は必須で、1〜600の整数を指定します。返された `result.url` をそのまま使用してください。内部 Runtime やブラウザー制御用ポートは共有できません。利用不可や権限不足が返された場合は、環境の運用担当者または Agent の所有者に、機能と必要な権限が有効か確認してください。

<h2 id="account">自分の Codex アカウントを接続</h2>

画面に接続入口がある場合は開始し、確認ページで表示されたデバイスコードを入力します。完了後 Hast に戻り、状態を確認します。

認証期限が切れたら再接続します。接続可否、モデル、利用枠は画面の権限とアカウント状態によって異なります。
