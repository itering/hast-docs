<h2 id="plan">製品の権限を確認</h2>

アバターメニューからアカウントセンターを開き、現在の Profile のプランを確認します。Task Agent や GTM の操作がロックされている場合は、Profile、プランの有効性、利用枠を確認してください。

価格、モデル、件数上限は現在の画面表示に従います。チームと個人では請求範囲が異なるため、購入前に Profile を確認します。

<h2 id="usage">使用量を確認</h2>

使用量画面で現在の期間の消費量を見ます。タスク前後の費用を比べる場合は同じ期間と Profile を使い、モデルアカウントの認証と Hast プランは別々に確認します。

追加枠が必要なチームメンバーは申請・承認の入口を使います。利用枠の問題はチームの請求管理者へ相談してください。

<h2 id="team">チーム席数</h2>

管理者はワークスペースでメンバーと招待を管理します。承認待ち招待は席を予約します。メンバーを削除しても購入済み席数は自動的に減らず、返金も自動ではありません。

削減する場合は次期の席数を変更します。アクティブメンバーと承認待ち招待に必要な席数未満にはできません。

<h2 id="renew">更新と解約</h2>

プラン・請求画面で更新状態と期間終了日を確認します。期末解約の場合、支払済み期間の権限は終了日まで続きます。変更の確定前に、適用時刻と料金を画面で確認してください。
