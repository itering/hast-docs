ワークベンチで Growth Agent を開きます。資料の参照や対応する操作を呼び出せます。最初にプロジェクト名を確認してください。

```text
現在の会社資料を確認し、記事テーマに影響する情報と不足している根拠を列挙してください。
```

<h2 id="operations">会話から操作を開始</h2>

サイト setup、PageSpeed、会社分析、プロジェクト文書、購買者の質問、AI Mention、Google Analytics 同期、X・記事タスクに対応します。

```text
このプロジェクトのモバイルとデスクトップの PageSpeed を実行してください。
```

```text
Article Agent を実行し、開発者向けの英語の手順記事を作成して Agents Feed に保存してください。
```

<h2 id="status">回答とバックグラウンド結果</h2>

「キューに登録」は処理を送信した状態です。`Run activity` で完了を確認し、対応するレポートや Feed で成果物を見ます。

追加質問や会話履歴の確認が可能です。会話の生成を停止しても、登録済みのプロジェクトタスクがすべて取消済みとは限りません。個別に状態を確認してください。
