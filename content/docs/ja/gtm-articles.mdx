<h2 id="configure">記事の要件を指定</h2>

`Run Article Agent` を開始し、目的に合わせて設定します。

| 設定 | 選択肢・説明 |
| --- | --- |
| スタイル | 手順、技術解説、比較、問題と解決、データと見解 |
| 言語 | 自動、英語、中国語 |
| 対象読者 | 誰が読み、何を既に知っているか |
| ファネル段階 | 自動、上部、中部、下部 |
| テーマ | 記事が答える具体的な問い |
| 対象クエリ | 対象の検索質問やキーワード |

例えば製品を知る開発者向けなら、英語の手順記事を選び、「注文照会アシスタントをサポートシステムへ接続する方法」をテーマにできます。

<h2 id="generate">生成を待つ</h2>

送信後は状態を確認します。1 回のタスクで長文 Markdown 原稿を 1 件生成し、完了後に Agents Feed へ表示します。

Growth Agent からも開始できます。Feed に保存したい場合は、会話の回答だけにならないよう Article Agent の実行を明示してください。

<h2 id="review">確認して利用</h2>

プレビューでタイトル、製品の事実、データ出典、リンクを確認します。Markdown を自分のコンテンツ管理システムへコピーし、公開先に合わせて編集します。

<Note>生成しただけではサイトに公開されません。未公開機能、顧客事例、効果の数値は事実を確認してから使ってください。</Note>
