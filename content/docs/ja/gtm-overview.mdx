Hast GTM は Hast AIP の市場・成長業務向けモジュールです。サイトからプロジェクトを作り、調査、GEO、技術分析、コンテンツ作成で会社と製品の背景を共有します。

サイトを入力すると内容を読み取り、会社・製品情報を整理して、性能、SEO、AI のブランド言及、トラフィックを分析します。X 投稿や記事の下書きも生成できます。

<h2 id="uses">適したマーケティング業務</h2>

サイト公開後は、製品の理解され方とサイトの問題を確認してから追加コンテンツを決める必要があります。GTM はこれらを同じプロジェクトで扱い、次の行動を検討しやすくします。

- 会社の位置付け、対象顧客、競合情報を整理し、調査や執筆の背景を準備する。
- 検索、サイト性能、AI のブランド言及から、さらに調べる点を見つける。
- プロジェクト資料から記事や投稿の下書きを作り、レビュー後に自社チャネルで利用する。

<h2 id="context">調査とコンテンツで背景を共有</h2>

サイト情報、会社プロフィール、関連文書を共通利用し、製品、読者、ブランド表現を毎回説明する手間を減らします。

初期化後に事実を確認してください。位置付けやサイト内容が変わったら、分析や下書き生成前に背景を更新します。[プロジェクト管理](gtm-projects)と[会社分析](gtm-company)を参照してください。

<h2 id="workspace">プロジェクト内の機能</h2>

| エリア | 用途 |
| --- | --- |
| 会社・サイト資料 | 製品、ブランド表現、競合、マーケティング文書 |
| SEO・Performance | モバイルとデスクトップの PageSpeed 結果 |
| GEO | 購買者の質問とモデル回答のブランド言及 |
| Traffic | Google Analytics 認証後のアクセス分析 |
| Agents Feed | X 投稿と記事の下書きのレビュー |
| Growth Agent | 質問や対応するプロジェクト操作の開始 |
| Run activity | バックグラウンドタスクの状態とイベント |

<h2 id="start">サイトから開始</h2>

[クイックスタート](gtm-quickstart)で作成し、初期化後にサイトと会社情報を確認してからコンテンツ作成を行います。

資料更新には setup を再実行します。新しい分析や原稿はバックグラウンドタスクの完了を待つ必要があり、キューへの登録だけでは結果は完成していません。

<h2 id="workflow">分析から次の行動へ</h2>

1. 会社、製品、読者情報を確認します。
2. 速度と SEO は [Performance](gtm-performance)、AI 言及は [GEO](gtm-geo)、アクセスは [Traffic](gtm-traffic) を選びます。
3. [記事](gtm-articles)や [X 原稿](gtm-x)を生成し、事実、リンク、ブランド表現を確認します。
4. 公開やサイト修正後、次回の分析で変化を確認します。

Traffic は Google Analytics 接続が必要です。生成物はレビューし、X 原稿は編集画面へのリンクから公開します。PageSpeed は問題の報告であり、サイトの修正は自分のサイト側で行います。

<h2 id="agent">Growth Agent で操作</h2>

[Growth Agent](gtm-growth-agent)では資料を見ながら質問し、対応する背景更新、分析、コンテンツ操作を開始できます。進捗と成果物は実行履歴で確認します。
