<h2 id="prepare">資料を準備</h2>

現在の Profile に Task Agent の利用権限があることを確認します。機密情報を含まない会議メモを準備するか入力欄に貼り付けます。この例は既存内容の整理だけなので外部アプリは不要です。

<Steps titleSize="h2">

<Step title="タスクを送信" id="prompt" stepNumber={1}>

新しい会話を開き、最後の段落を実際のメモに置き換えます。

```text
以下の会議メモを日本語の議事録にしてください。
決定事項と、まだ議論が必要な事項を分けてください。
アクションには内容、担当者、期限を記載し、原文にない情報は「要確認」としてください。
Markdown ファイルを作成し、回答には私が確認すべき点をまとめてください。

会議メモ：
サポート部門は注文照会機能を希望。初版は状態確認だけで注文変更は行わない。
林さんが金曜日までに API 項目を確認する。公開日は未定。
```

ファイルを添付する場合は、アップロード完了後に送信します。

</Step>

<Step title="進捗を確認" id="plan" stepNumber={2}>

送信すると Agent が実行を開始します。回答と実行記録を確認し、範囲、形式、情報源を変える必要があれば補足します。中断する場合は停止操作を使います。業界調査が不要なら「このメモだけを整理し、外部調査はしないで」と伝えます。

</Step>

<Step title="確認とダウンロード" id="result" stepNumber={3}>

実行後、担当者、日付、事項が原文に基づくか確認します。会話メニューから会話内のファイルを開き、Markdown をダウンロードします。

修正するなら同じ会話で「アクションを表にし、未確認事項を残して」と依頼します。問題があれば[トラブルシューティング](task-troubleshooting)を参照してください。

</Step>

</Steps>
