HAST Desktop は macOS Universal ディスクイメージとして提供されています。公開リリース一覧で最新の安定版を確認できます。一覧にはバージョン、ファイルサイズ、SHA-256 チェックサムも記載されています。

<h2 id="download">安定版をダウンロードする</h2>

[HAST Desktop のリリース一覧](https://hast-desktop.fra1.digitaloceanspaces.com/releases.json)を開き、安定版の macOS（`darwin-universal`）の項目を選びます。prereleases または development に掲載された項目は選ばないでください。その項目の installer URL を開いて `.dmg` ファイルをダウンロードします。

<h2 id="install">HAST Desktop をインストールして起動する</h2>

ダウンロードしたディスクイメージを開き、HAST Desktop の macOS インストール手順に従います。インストール後にアプリを起動し、プロジェクトの作成や読み込みの前に HAST にサインインしてください。ワークスペース機能にはサインインが必要です。

<h2 id="verify">リリース情報を確認する</h2>

リリース一覧には各ダウンロードのバージョン、SHA-256 チェックサム、バイト単位のサイズが記載されています。ダウンロードを検証する場合は、同じ安定版の項目にある値と照合してください。最新のインストーラー URL はリリース一覧で確認できます。以前のリリースのリンクは最新ではない場合があります。
