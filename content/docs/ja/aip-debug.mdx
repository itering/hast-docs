<h2 id="start">デバッグを開始</h2>

Agent を保存し、詳細からデバッグを開きます。デバッグ画面から現在の Profile の Agent を選ぶこともできます。

1. デバッグセッションを作成します。
2. 主な役割を検証するメッセージを送信します。
3. 応答とイベントデータを確認します。
4. 追加質問で会話の文脈を保持するか確認します。

設定済みツールは実際に実行されます。業務データを書き換えるツールでは、操作権限のあるテスト対象を使ってください。

長い内容は省略表示しています。実行には影響しません。

<h2 id="check">結果を確認</h2>

| 確認項目 | 例 |
| --- | --- |
| 入力の完全性 | 注文番号がなければ作り出さずに質問する |
| 資料の利用 | 正しい資料を使い、不足情報を認める |
| ツール呼び出し | 引数が正しく、認証失敗が明確に示される |
| 出力形式 | システムプロンプトの指定に従う |
| 会話の継続 | 同じセッションの文脈で追加質問に答える |

<h2 id="stop">停止と再接続</h2>

中断するには停止を使います。イベント接続を切ったりページを閉じたりしても実行は停止しません。

切断後は読み取り済みのイベント位置から再接続できます。デバッグのセッション状態は現在のページに保持されるため、離れる前に調査用のセッション ID やエラーを記録してください。

<h2 id="errors">よくある問題</h2>

会話の実行権限が変更された場合、入力内容は保持されます。現在の権限で実行するには、新しい会話を開始してください。

設定が反映されない場合は保存と選択中の Agent を確認します。呼び出し拒否は有効状態、ツール認証失敗はシークレットとバインドを確認します。資料が見つからない場合は索引完了と Agent での選択を確認してください。
