<h2 id="enable">メモリを有効化</h2>

Agent の設定で長期メモリを有効にし、読み取り範囲と書き込み先を選んで保存します。メモリ項目を作成するだけでは Agent のメモリ機能は有効になりません。

<h2 id="scope">範囲を選択</h2>

| 読み取り範囲 | 読める内容 |
| --- | --- |
| `self` | 現在の Agent 自身のメモリ |
| `webhook` | 現在の Profile の Webhook メモリと共有メモリ |
| `all` | Webhook の範囲に加え、現在の Profile の Task Agent メモリ |

書き込み先は `self` または `shared` です。共有先への書き込みには `webhook` または `all` の読み取り範囲が必要です。読み取りを `self` に変更すると、フォームの書き込み先も `self` に変わります。

新規 Agent は自身の読み書きが既定です。既存 Agent、特に広い読み取り範囲を持つ設定では、画面の値を確認してください。

<h2 id="manage">項目を管理</h2>

メモリ画面で Task Agent、Webhook 共有、特定の Agent を絞り込めます。名前と内容を入力し、顧客用語、レポート形式、長期的な制約などを保存します。

名前は 128 文字以下で、同じ所有範囲内で一意にします。内容は空でなく 256 KiB 以下です。新しい Agent 専用のメモリは、Agent の保存後に作成できます。

内容の編集や所有先の移動が可能です。変更は後続の読み取りに反映され、実行中のタスクの文脈は自動更新されません。Agent 削除後に残ったメモリも移動・削除できます。
