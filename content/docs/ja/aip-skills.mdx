Skill には繰り返し使う作業方法を保存します。パッケージには入口ファイルと付属資料を含められます。Agent が利用するには、その設定で Skill を選択する必要があります。

<h2 id="create">Skill を作成</h2>

1. Skills から新規作成を開きます。
2. ディレクトリ名、表示名、説明を入力します。
3. 通常は `SKILL.md` を入口ファイルとして記述します。
4. テンプレートや参考資料が必要なら付属テキストファイルを追加します。
5. 保存後、Agent 編集画面でリソース一覧を更新し、Skill を選択して Agent を保存します。

```markdown
---
name: requirements-brief
description: 提示された要件をレビュー用の日本語の概要に整理します。
---

# 要件概要

ユーザーが示した日付、数値、製品名を保持します。
目標を要約した後、制約と未確認事項を列挙します。
記載のない情報は「要確認」とします。
プロジェクト文書にコピーしやすいよう Markdown で出力します。
```

<h2 id="import">既存の Skill をインポート</h2>

ローカルのファイルやディレクトリ、GitHub、HTTPS URL からインポートできます。ローカルからのインポートは下書きのファイル一式を置き換えるため、必要な内容を事前に保存してください。

入口ファイル、相対パス、付属ファイルを確認して保存します。各ファイルは UTF-8 テキストで 256 KiB 以下、パッケージ全体は 1 MiB 以下です。

<h2 id="maintain">編集・無効化・削除</h2>

システム Skill は読み取り専用です。個人 Skill は編集・無効化できますが、作成済みのディレクトリ名は変更できません。無効化は現在の Profile の後続実行に影響し、Agent フォームで無効な個人 Skill を新たに選択できなくなります。

保存時はファイル一式を送信します。未読み込みの付属ファイルを不要と判断しないでください。内容変更の通知が出た場合は再読み込みしてから編集します。

参照中の Skill を削除する前に、関連 Agent の設定から外して保存してください。
