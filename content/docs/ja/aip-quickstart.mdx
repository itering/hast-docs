この例では、既知の情報と未確認事項を分けて整理する「要件整理アシスタント」を作ります。まずテキストだけで会話を確認し、その後に業務ツールを追加します。

<h2 id="prepare">準備</h2>

AIP にログインし、アバターメニューの Profile を確認します。Agent 一覧を開けることと、利用可能なモデルを読み込めることが必要です。

<Steps titleSize="h2">

<Step title="作成と保存" id="create" stepNumber={1}>

1. Agent 一覧から新規作成画面を開きます。
2. 名前を「要件整理アシスタント」、説明を「目標、制約、未確認事項を整理」にします。
3. 以下のシステムプロンプトを入力します。
4. 利用可能なモデルを選び、推論強度が表示される場合は必要な値を指定します。
5. 呼び出しを有効にします。この例では業務ツールやシークレットは不要です。
6. 保存し、詳細画面に移動したことを確認します。

```text
ユーザーが提示した要件を整理してください。
最初に目標を一段落でまとめ、既知の制約と未確認事項を列挙します。
原文の数値、日付、名前を保持してください。
記載のない情報は「要確認」とし、推測を事実として補わないでください。
日本語で回答してください。
```

</Step>

<Step title="テストメッセージを送信" id="test" stepNumber={2}>

詳細画面からデバッグを開き、作成した Agent を選択してセッションを作成し、次を送信します。

```text
顧客向けに注文照会アシスタントを作ります。サポート担当者がチャットで注文番号を入力します。
今月中に初版を完成させたいです。まずは状態照会だけに対応し、注文は変更しません。
この要件を整理してください。
```

「今月」「状態照会のみ」が保持され、不明な API 情報が要確認になっているか確認します。続けて「未確認事項を優先順位順に並べて」と送り、前の文脈を引き継ぐか確認してください。

</Step>

</Steps>
