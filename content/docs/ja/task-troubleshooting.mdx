<h2 id="questions">よくある質問</h2>

<AccordionGroup>
<Accordion title="タスクを開始できない" id="access">現在の Profile と Task Agent を含むプランか確認します。モデル一覧の読み込みに失敗したら再試行し、利用できないモデルの場合はタスク実行対応のモデルを選びます。</Accordion>
<Accordion title="計画だけでファイルがない" id="planning">新しいメッセージは直接実行に進みます。回答内の計画は作業手順の説明です。終了後も回答文だけなら、必要な形式でファイルに保存するよう依頼し、ファイル一覧で結果を確認してください。</Accordion>
<Accordion title="切断後に再送信すべきか" id="connection">まず元の会話を開き直して状態を確認します。まだ実行中の可能性があり、再送信は新たな作業を生む場合があります。中断には停止を使います。</Accordion>
<Accordion title="接続済みアプリを読めない" id="apps">コネクターの状態と認証アカウントを確認し、そのアカウント自体が対象ファイルやプロジェクトにアクセスできるか調べます。期限切れなら再接続し、Unavailable なら管理者に連携設定の確認を依頼します。</Accordion>
<Accordion title="ファイルが見つからない" id="missing-file">元の会話からファイルを開いて更新し、Agent が保存を完了したか確認します。本文だけが返されたなら、ファイル保存を依頼してください。[ファイルガイド](task-files)も参照できます。</Accordion>
</AccordionGroup>

<h2 id="support">問い合わせに含める情報</h2>

製品名、発生時刻とタイムゾーン、Profile、セッションまたはタスク ID、画面のエラー、期待する結果を記録します。API キー、呼び出し URL の認証情報、業務シークレットの値は含めないでください。
