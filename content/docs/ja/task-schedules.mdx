<h2 id="create">スケジュールを作成</h2>

閲覧のみのワークスペースでは、スケジュールを確認できますが、作成・編集・一時停止・再開・削除はできません。

1. スケジュール画面で新規作成を選びます。
2. 「前回を繰り返す」だけでなく、毎回の完全な指示を記載します。
3. 毎時、毎日、平日、毎週から選び、時刻を設定します。
4. 詳細設定でタイムゾーン、モデル、推論強度を確認します。
5. 保存し、一覧の次回実行を確認します。

```text
指定プロジェクトで過去 1 日に作成された新しい課題を整理してください。
タイトル、リンク、現在の状態を含む日本語の概要にしてください。
新規課題がなければ「過去 1 日に新しい課題はありません」と明記してください。
```

必要な外部アプリを先にコネクターで認証し、プロジェクトを具体的に指定します。

<h2 id="cron">カスタム Cron</h2>

詳細設定では 5 フィールドの Cron を使えます。以下は指定タイムゾーンの毎週月曜日 09:00 です。

```text
0 9 * * 1
```

`Asia/Shanghai` などのタイムゾーン名を指定します。保存後に次回実行を確認し、ブラウザの現地時刻と混同しないでください。

<h2 id="runs">結果を確認</h2>

スケジュールを選び、最近の実行で状態と出力を確認し、関連タスクやファイルを開けます。複数の Agent の実行状況を比較するには、[Agent の実行レポート](aip-debug#run-report)を開きます。履歴は閲覧専用です。次回の動作はスケジュールの指示を編集して変更します。

<h2 id="saved-assignment">保存したチームタスクの結果について質問する</h2>

チームタスクを保存すると、その時点のリード、メンバー、権限の範囲、既定の設定が記録されます。その後のチーム変更は新しい割り当てに適用されます。既存タスクの次回以降の実行にも反映するには、タスクのチーム割り当てを編集して保存し直します。

タスク履歴で確認したい実行を開きます。後から別の実行が完了しても、選択した実行の結果は保持されます。チームで話を続けるには **元の会話を開く** を選びます。単独 Agent の実行で **Assistant に質問** が表示された場合は、そこから質問できます。今のチャットで以前の結果について質問するときは、タスクと対象の実行を指定してください。タスクを再実行するには **1 回実行** を選びます。

イベントをトピック単位で扱うタスクでは、新しい Webhook イベントを元の作業の続きとして処理できます。その入力を読めるのは、元の作業に参加し、現在もそのタスクに割り当てられている Agent だけです。同じイベントの再送には元の受付記録が使われます。非公開の指示と選択済みのナレッジには、既存のアクセス権が適用されます。

<h2 id="pause">一時停止・再開・削除</h2>

一時停止は今後の自動実行を止めます。再開後は次回実行を確認します。スケジュール削除も後続の自動実行を止めるため、対象を確認してください。

有効なスケジュールでも各実行の成功は保証されません。失敗時は履歴、モデル、認証、入力資料を確認します。

<h2 id="preconditions">任意の Python 前提条件</h2>

定時タスクでは、Agent を起動する前に読み取り専用の Python スクリプトで条件を確認できます。スクリプトはスケジュール ID、実行時刻、トリガーを標準入力から JSON で読み取り、出力の最終行に JSON で判定結果を返します。

- `{"run":true}` は Agent を起動します。`context` を追加すると実行にデータを渡せます。
- `{"run":false,"reason":"No changes"}` は Agent の起動をスキップし、理由を実行履歴に記録します。
- スクリプトのエラー、タイムアウト、無効な判定は実行履歴に失敗として記録されます。診断内容を確認し、スクリプトや入力を修正して **1 回実行** で確認します。
