<h2 id="switch">プロジェクトを識別して切り替え</h2>

切り替えメニューでサイトを選びます。分析や生成の前に名前と URL を確認し、別の利用主体のプロジェクトを見る場合は先に Profile を切り替えます。

<h2 id="refresh">サイト資料を更新</h2>

サイト変更後、実行メニューの `Run setup` を選ぶか、Growth Agent に依頼します。

```text
このプロジェクトのサイト資料を更新し、ページと公開サイトファイルを再取得して、キューに登録したタスクを教えてください。
```

setup 完了後に資料を確認します。実行中は重複して開始できない操作があります。

<h2 id="files">サイトファイルを確認</h2>

`llms.txt`、`robots.txt`、`sitemap.xml`、アイコン、取得済みページなどを表示できます。HTTP 状態に注意してください。404 はその URL でファイルが返らなかった意味で、プロジェクト全体の失敗とは限りません。

これらはサイトから取得した資料です。setup を実行してもサイトのファイルは変更されません。

<h2 id="settings">名前の変更と削除</h2>

設定画面で名前の変更や削除を行います。変更後は切り替えメニューの表示を確認します。削除前に必要なレポートや原稿を保存し、対象サイトを確認してください。
