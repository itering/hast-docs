<h2 id="import">設定をインポート</h2>

編集画面で AIP テンプレートまたは互換 Hook JSON をインポートします。プレビューを確認し、現在の下書きの置き換えを承認してから保存します。

現在の Profile の Skills とナレッジベースを確認し、存在しない、または利用できないリソースは選択から除外してプレビューに表示します。一覧の読み込み失敗時は再試行してからインポートしてください。

<h2 id="copy">Agent を複製</h2>

詳細画面で新しい Agent としてコピーする操作を選びます。下書きを確認し、名前と個別に管理したい設定を変更して作成します。新しい Agent は独立した呼び出し口を持ち、複製側の変更は元の Agent に反映されません。

<h2 id="export">エクスポートと引き継ぎ</h2>

呼び出し認証情報、シークレットの値、バインドは含まれません。ツールヘッダーに直接記載した値や URL クエリ値はプレースホルダーに置き換わり、シークレット参照は保持されます。

共有前にプロンプト、説明、業務パスなどの自由記述も確認してください。別の Profile へインポートしたら、リソースを選び直し、バインドとプレースホルダーを補ってデバッグします。

エクスポートは手動復元に使えますが、自動ロールバック画面はありません。
