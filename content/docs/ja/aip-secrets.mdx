<h2 id="create">シークレットを作成</h2>

<Note>シークレット画面で名前と値を入力し、保存します。注文システムのトークンなら `ORDER_API_TOKEN` などの名前にします。保存後の一覧には名前などの情報だけが表示され、値は再表示されません。</Note>

<h2 id="bind">Agent にバインド</h2>

1. Agent 編集画面のシークレット設定を開きます。
2. 現在の Profile に保存済みのシークレットを選択します。
3. 業務 HTTP ツールのリクエストヘッダーで名前を参照します。
4. Agent を保存し、デバッグで認証を確認します。

```text
Authorization: Bearer ${ORDER_API_TOKEN}
```

プレースホルダーの名前はバインドした名前と一致させます。作成しただけでバインドしていない認証情報はツールで利用できません。

実行環境に認証ファイルが必要な場合は、画面に従ってパスとデコード方法を指定し、ファイルとしてバインドします。ツールが必要とする場合だけ設定してください。

<h2 id="rotate">更新と削除</h2>

更新では名前を変えずに値を置き換えます。業務システムでトークンを更新したら、対応する項目も更新し、呼び出しをテストします。

Agent やセッションが参照しているシークレットは削除できない場合があります。先にバインドを外して保存してください。Agent の呼び出し URL 内の認証情報とは用途が異なります。[HTTP 接続](aip-api)を参照してください。
